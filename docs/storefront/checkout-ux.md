## ما تحتاجه الخريطة لتعمل

الكود جاهز، والمطلوب إعداد في Google Cloud:

1. مشروع في Google Cloud مع **حساب فوترة مفعّل**. بدونه تظهر «الخريطة غير متاحة حاليًا»، والاستخدام العادي يقع غالبًا ضمن الرصيد الشهري المجاني.
2. تفعيل ثلاث واجهات: **Maps JavaScript API** و**Places API (New)** و**Geocoding API**.
3. مفتاح API مقيّد بـ **HTTP referrers** على نطاقات الموقع (مثل `https://example.com/*`) و`http://localhost:3001/*` للتطوير، ومقيّد بالواجهات الثلاث فقط.
4. **Map ID**: من Map Management أنشئ معرّف خريطة نوعها JavaScript/Vector. يلزم لعلامة الموقع (Advanced Marker)؛ بدونه يُستخدم `DEMO_MAP_ID` وهو للتطوير فقط.
5. في GitHub (المستودع ← Settings ← Secrets and variables ← Actions):
   - Secret: `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY`
   - Variable (أو Secret): `NEXT_PUBLIC_GOOGLE_MAPS_MAP_ID`
6. محليًا: نفس القيمتين في `.env` للواجهة. لأن القيم `NEXT_PUBLIC_*` تُضمَّن وقت البناء، يلزم إعادة بناء الواجهة ونشرها بعد إضافتهما.

الخريطة تتبع دولة المتجر: منطقة النتائج، والبحث عن الأماكن محصور في الدولة، ومركز الخريطة الافتراضي عاصمتها.
